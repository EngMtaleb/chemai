How they are built

The same rules for every project.

  • Limits are publishedEach tool states what it cannot do, next to the answer it gives.
  • Negative results stayA model that lost to a simpler rule is recorded with the number that shows it.
  • Errors become testsEvery mistake found during the work is now a test that fails if it comes back.
