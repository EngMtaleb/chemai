## What ran, and what did not
- **Stages 1 and 2 ran** (D2′ and scoring).
- **Stages 3 and 4 did not**, because none of the three new encoders loaded:
  - **BEATs iter3:** "no download of BEATs_iter3.pt worked". Both the authors' OneDrive link and the Azure copy failed.
  - **EAT-base and EAT-large:** `AttributeError: 'EATModel' object has no attribute 'all_tied_weights_keys'`.
    - This is our loader's failure, not the models'. Transformers 5 sets that attribute in `PreTrainedModel.post_init()`, and EAT's remote code does not call it.
    - The same error is reported for other remote-code models under transformers 5 (huggingface/transformers issue 43883; jinaai/xlm-roberta-flash-implementation discussion 62).
- So the screen had only the reference encoder, the selection was empty, and N0, N1 and N2 were not run. As the rules say, each failure is reported as ours.
